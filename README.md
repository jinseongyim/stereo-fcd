# Fréchet ChemNet Distance is blind to double-bond stereochemistry

FCD is the default distributional metric for molecular generative models. It
cannot see whether a double bond is *E* or *Z*.

This is not an approximation that degrades gracefully. The two SMILES characters
that carry the distinction, `/` and `\`, are absent from ChemNet's 35-token
vocabulary, so the tokenizer routes both to its unknown token. Two isomers arrive
at the network as **one identical token sequence**:

```
Z    …/C=C\…   ─┐
                ├─► tokenizer ─►  … X C = C X …  ─►  one activation
E    …/C=C/…   ─┘
```

The encoder is not approximating the difference poorly. It never receives it.

## What that costs

| measurement | result |
|---|---|
| E/Z pair activations, order-preserving SMILES writer | max&#124;Δa&#124; **exactly 0** on 4,000/4,000 pairs |
| E/Z pair activations, canonical writer | 7/4,000 differ — all from atom reordering, not stereochemistry |
| Invert **every** double bond in MolT5-large's output | FCD 0.386803 → 0.386801 (**−0.001 σ**) |
| …while per-bond correctness on the same molecules | **289/292 → 3/292** |
| Delete the same stereochemistry instead of inverting it | **41.8 σ** |
| Replace 2 % of molecules with unrelated ones | 1.56 σ |

Inverting the stereochemistry of every molecule moves the metric less than
swapping one molecule in fifty. Deleting the same information moves it four
thousand times more, because deletion shortens the token sequence and inversion
does not.

**It is specific, not general.** `@` *is* in the vocabulary, and the same encoder
separates esomeprazole from (*R*)-omeprazole (1.14), escitalopram from
(*R*)-citalopram (0.41), and the naproxen and levofloxacin antipodes. FCD is not
blind to stereochemistry; it is blind to the two characters that carry *E*/*Z*.

**It is not rare.** 10.6 % of ChEMBL and 21.6 % of the ChEBI-20 test split carry
at least one *E*/*Z* bond. On 908 bonds where two published text-to-molecule
models both recover the skeleton, stereochemical recall is 0.256 against 0.997 —
and on the captions where both are FCD-eligible, the paired bootstrap interval
for the FCD difference includes zero. The metric does not track a nearly
four-fold difference in stereochemical fidelity.

## Reproducing the central claim

```bash
pip install -r requirements.txt
python 01_verify_chemnet_collapse.py   # the vocabulary collapse, with the @ control
python 09_molt5_generate.py            # generate on the ChEBI-20 test split
python 15b_c2_full_correct.py          # invert everything, verified, and score FCD
python 35_protocolB_actual.py          # score the same inverted molecules against truth
python 22_flip_vs_strip_repeated.py    # flip vs strip vs substitution, 15 draws
```

`15b` and `35` are the pair that matters: the first shows the metric does not
move under a complete, verified inversion; the second shows the molecules really
did change (98.97 % → 1.03 % per-bond) on that same inverted set.

Full step-by-step notes, environment pins, and the two setup traps that will
otherwise cost you an afternoon are in **[REPRODUCING.md](REPRODUCING.md)**.
The external datasets are not redistributed here — see **[DATA.md](DATA.md)**.

## Inverting stereochemistry is easy to get silently wrong

Three RDKit idioms under-invert, and each makes the effect look smaller than it
is. Building an `RWMol` copy and setting bond stereo returns the original
molecule. Flipping the `STEREOE`/`STEREOZ` enum and re-canonicalizing no-ops on
bonds that already carry directional neighbours on both ends. A direction-search
heuristic leaves about 12 % of bonds unflipped.

The diagnostic is simple and worth reusing: a stereogenic double bond carrying a
CIP label **must** change that label when inverted, so any surviving label is a
broken inversion, not evidence of symmetry. `36_inversion_methods.py` compares
the methods; the audited one flips all 292 mapped bonds.

RDKit's legacy CIP perception is a second trap — it labels esomeprazole *R*,
where the accepted configuration is *S*. Carbon centres agree between
implementations, so the discrepancy is easy to miss. Call
`rdCIPLabeler.AssignCIPLabels` explicitly.

## Layout

The directory is flat on purpose: every script resolves its inputs relative to
its own location, so reproduction works from a clone with no path configuration.

- `00_*.py` … `39_*.py`, `44_*.py` — the analysis, in the order it was run
- `*.json` — every number in the paper, as produced by those scripts
- `figure1.pdf`, `figure2.pdf` — the paper's figures, regenerated by
  `38_figure_drugs.py` and `19_figure1.py`
- `stereo_head.pt` — the trained corrective head, provided so that the negative
  result about it can be checked rather than taken on trust
